## 🚀 Cara Menjalankan Website

### Opsi 1: Menggunakan Perintah `php artisan serve` (Sesuai Permintaan)
Buka terminal / PowerShell di folder proyek ini, lalu jalankan:
```bash
php artisan serve
```
Server development akan langsung aktif di:
👉 **`http://127.0.0.1:8000`**

### Opsi 2: Menggunakan Perintah Asli PHP Server
```bash
php -S localhost:8000
```

### Opsi 3: Langsung di Komputer / Laptop (Offline)
* Cukup klik ganda (*double-click*) file `buka-website.bat` atau langsung klik ganda `index.html`.
* Website akan terbuka langsung di browser bawaan Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).

### Opsi 4: Menggunakan Local Server (Node.js / Python)
```bash
# Menggunakan Node.js
npx serve .

# ATAU menggunakan Python
python -m http.server 8080
```
Buka browser di `http://localhost:8080`.

### Opsi 3: Deploy ke Hosting Publik
Website ini adalah **Pure Static Web** (HTML, CSS, JS murni tanpa butuh database server berat). Anda dapat langsung mengunggah folder ini ke:
* **cPanel Hosting / Rumahweb / Niagahoster / JagoWeb:** Upload seluruh isi folder ke `public_html`.
* **GitHub Pages:** Push repo ini ke GitHub dan aktifkan *Pages* dari branch `main`.
* **Vercel / Netlify:** Drag & drop folder ini langsung untuk online instan gratis.
